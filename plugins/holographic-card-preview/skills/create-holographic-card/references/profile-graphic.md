# Graphic Profile

Use for poster-like, editorial, abstract, or layout-led artwork. Define hierarchy with negative space, a primary anchor, secondary marks, and a restrained palette. Describe grids, blocks, paper, print, or texture only as visible visual facts; do not describe design rationale.

Use `TYPE` only when the user requests visible words. Quote the exact short text, give its location and visual role, and warn through the final prompt only when legibility is critical. Never invent labels, dates, logos, CTA copy, or brand marks.

For holographic card art, keep the raster text-free and full-bleed. Use the complete 5:7 canvas for the image, avoid game-card conventions, and favour a clear primary anchor over dense decoration.
