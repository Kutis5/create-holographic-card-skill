# Preview Layered Holographic Card

Use `preview_holographic_card` once with `background_path`, `subject_path`, `art_alt`, and `presentation`; optionally add a back. The tool only returns the preview result and does not control the host. Open its `previewUrl` with one minimal Browser navigation in Codex's in-app Browser, inspect the accessible error state and warnings, and leave the successful tab as the deliverable. Do not add a host-opening argument, reopen the URL, create a widget, use fullscreen, scaffold a temporary website, or fall back to an external browser.

Before calling, confirm both layers use the same 5:7 canvas and the subject PNG has meaningful transparent and opaque pixels with a non-full-canvas alpha bounding box. Use the `create-holographic-card` workflow to produce or repair layers; this preview tool does not segment images.

The card contains no title, description, tag, serial, status, or candidate UI. The background fills the inner card. The transparent subject is a decorative repeated layer hidden from assistive technology; the background image carries `art_alt`. Pointer, touch, keyboard arrows/Home, optional Enter/Space flip, and reduced motion remain available.

Select only one material family, one compatible microtexture, targets, a one-to-six-color palette, and strengths. First classify the artwork: light, low-saturation, pastel, or product-photography art uses restrained silver foil with an explicit six-stop low-saturation palette and foil `0.28`, texture `0.32`, glare `0.36`; vivid, iridescent, fantasy, or explicitly rainbow art uses the flagship rainbow palette with foil `0.78`, texture `0.48`, glare `0.62`. Silver foil must preserve the subject's inherent color and hierarchy at idle, without broad white clipping or distinct pink, green, or blue bands. Every material keeps the shared counter-moving optical fields, local glare/darkening, edge glow, shadow, and automatic idle sweep; the material family changes only microtexture. Never add a repeating diagonal stripe overlay. Draw the whole optical plane below the transparent subject: background, WebGL, coat, soft color fields, sparkle and glare never attach to subject pixels. The subject may parallax and cast only an achromatic natural shadow; it receives no foil, texture, sparkle, glare, colored shaping, or rim light. The WebGL2 renderer expands public values through its fixed GPU Optical Recipe Registry v2; never add shader uniforms, layer parameters, CSS, filters, masks, or motion coefficients. Patterned surface effects resolve to the subject-excluded background and report a warning. `depth.rimIntensity` remains accepted only for old Presentation data and has no visual effect. WebGL2 initialization, shader compilation, texture upload, or context-loss failures block the preview with an explicit error; do not create a flat or CSS material fallback.

Frame color may stay fixed or adapt from the outer 20% of each face. Use `frame.colorMode: "image"` for adaptive front/back palettes and keep the required `frame.color` as the fallback. Omit `colorMode` or use `fixed` for an exact manual border color. Pixel-read failures fall back without becoming a preview error.

The process serves only from `127.0.0.1`, stores normalized images in memory for 15 minutes, and rejects legacy candidates, content, batches, selection, arbitrary CSS, invalid Alpha, mismatched canvases, or unsafe effect/depth values. Inspect warnings and report an exact failure instead of producing a flat fallback.
